# 1-ci dərs: Cins və İsmin halı

- **`erebce-ders-1-cins-ve-hallar.pdf`** — 7 səhifəlik A4 dərslik:
  üz qabığı → lüğət (21 söz) → Qayda 1: Cins (müzəkkər / müənnəs) → Qayda 2: İsmin halı (raf'un, cərrun, nasbun) → 7 çalışma → cavablar.
- **`interaktiv-versiya.html`** — eyni dərsin rəngli, interaktiv veb variantı (sözün cinsini/halını seçmək, mini-test). Brauzerdə açılır.
- **`menbe/`** — PDF-in mənbəyi. Dəyişiklik etmək üçün `ders.html`-i redaktə edin və yenidən yaradın:

```bash
cd menbe
npm install
npm run pdf
```

Lazımdır: Node.js və Playwright (Chromium).
